# VictoryPVI

VictoryPVI 是一个由独立社区贡献者维护的第三方消融记录辅助工具，用于记录肺静脉消融位置、覆盖次数、序列进度与终点评估，并可在本地生成汇总报告。

本项目为社区维护的非官方项目，不隶属于、不代表，也未获得任何设备厂商、软件平台或医疗机构的官方背书。页面中出现的产品名称仅用于说明兼容或应用场景，相关商标和产品名称归各自权利人所有。

## 使用方式

直接使用现代浏览器打开 `index.html`，或通过静态文件服务器部署。应用默认不连接外部服务，消融记录保存在当前浏览器的 `localStorage` 中；需要多端实时跟随时，使用页面中的本地设备同步。

## 多端设备同步

平时直接使用网页，只有电脑需要多端同步时才下载客户端。手机和平板始终只用浏览器。

1. 电脑网页点击“设备同步”，按系统下载 Windows 或 Mac 客户端，完整解压后双击 VictoryPVI。
2. 回到原网页，点“已启动，连接并继续记录”。当前消融记录会带入本地窗口。
3. 手机和电脑连接同一 Wi-Fi / 热点，用手机相机扫描电脑二维码并在浏览器打开。多台手机可以扫描同一个二维码。

客户端通过 [GitHub Releases](https://github.com/JialinLIU1993/VictoryPVI/releases) 分发，包含运行环境，不需要安装开发工具。Windows 版支持 Windows 10 / 11 x64；Mac 版支持 macOS 13.5 及以上，兼容 Intel 与 Apple Silicon。首次运行可能需要允许系统打开应用、访问本地网络或通过防火墙。当前分发包未做商业签名/Apple 公证。

同步不访问在线服务。记录在主机电脑持久保存，手机只读跟随；刷新、网络短暂中断、电脑程序重启后会自动重新连接。同一地址下不需重新扫码；更换网络导致地址变化时，扫描新二维码即可。电脑应保持客户端运行、避免休眠，网络需允许设备互访。退出时，在同步窗口点“退出电脑客户端”。

从网页带入的是当前记录、术式设置、PVI 终点和电极选择；患者信息、PDF 和撤回历史不会转移。原网页的本机记录保留。新打开的操作窗口接管编辑，旧操作窗口自动停用，避免多个窗口互相覆盖。

电脑记录位置：Windows `%LOCALAPPDATA%\VictoryPVI\record.json`；Mac `~/Library/Application Support/VictoryPVI/record.json`。删除或更换客户端不会删除这些记录。

实现、构建及发布说明见 [SYNC_DESIGN.md](./SYNC_DESIGN.md)。

报告中的患者信息均为选填，仅在当前页面内用于生成本次报告，不写入应用的本地存储。点击“导出 PDF 报告”后，应用会将患者基础信息、当前肺静脉消融分布和消融概览按照固定 A4 竖向版式在当前设备本地直接生成并下载；文字使用嵌入式中文字体，扇区图、表格、边框和进度条均以 PDF 原生矢量内容绘制，不调用浏览器打印功能，也不依赖网络服务。较长的“其它信息”会自动续排到后续页面，避免内容裁切。导出的 PDF 报告可能包含用户主动填写的信息，请按照所在机构的数据与隐私要求妥善处理。

普通单根肺静脉判定为消融完成需同时满足：前庭 8 个扇区均达到各自完成阈值，且该肺静脉口部与前庭的总消融次数不少于 4 次。其它扇区覆盖情况会继续单独显示；消融完成判定不替代 PVI 电生理终点评估。
