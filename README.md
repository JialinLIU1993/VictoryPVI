# VictoryPVI

VictoryPVI 是一个由独立社区贡献者维护的第三方消融记录辅助工具，用于记录肺静脉消融位置、覆盖次数、序列进度与终点评估，并可在本地生成汇总报告。

本项目为社区维护的非官方项目，不隶属于、不代表，也未获得任何设备厂商、软件平台或医疗机构的官方背书。页面中出现的产品名称仅用于说明兼容或应用场景，相关商标和产品名称归各自权利人所有。

## 使用方式

直接使用现代浏览器打开 `index.html`，或通过静态文件服务器部署。应用默认不连接外部服务，消融记录保存在当前浏览器的 `localStorage` 中；需要多端实时跟随时，使用页面中的本地设备同步。

## 多端设备同步

手机、平板、电脑都可以作为操作端。提供两种本地方式，不使用在线同步服务。

**只有手机：** 两台手机连接同一 Wi-Fi / 热点，打开网页中的“设备同步 → 手机之间连接”。操作手机点“本机操作，连接其他手机”，另一台点“扫码跟随另一台手机”并扫描邀请；操作手机再扫对方回码。可添加多台手机，记录直接在手机之间传输和保存，无需电脑。短暂中断恢复后补发最新状态；刷新或关闭网页后需要重新扫码。首次使用先联网打开网页及扫码功能，把组件加载完成。

**电脑提供连接和保存：**

1. 电脑网页点击“设备同步”，下载 Windows 或 Mac 客户端，完整解压后双击 VictoryPVI。
2. 回到原网页，点“已启动，连接并继续记录”，当前消融记录会带入本地窗口。
3. 手机扫描电脑二维码并在浏览器打开，默认跟随。手机或其他设备想操作时，点“设备同步 → 改为本机操作”，原操作端自动转为跟随。

同一时刻只有一个操作端；手机操作时拥有记录、撤回、术式设置和导出能力。刷新操作页面会恢复原操作会话，重新打开电脑窗口不会抢走手机的操作权。断线未确认的操作独立保存在原写入会话中，只有服务端仍认可该会话时才补发，避免旧操作覆盖新记录。

电脑连接模式下，最新记录在电脑持久保存；手机刷新、短暂断线、电脑程序重启后自动连接。电脑应保持客户端运行、避免休眠。两种方式均要求局域网允许设备互访；更换网络后需要重新连接。

客户端通过 [GitHub Releases](https://github.com/JialinLIU1993/VictoryPVI/releases) 分发，包含运行环境。Windows 版支持 Windows 10 / 11 x64；Mac 版支持 macOS 13.5 及以上，兼容 Intel 与 Apple Silicon。首次运行可能需要允许系统打开应用、本地网络访问或通过防火墙。当前包未做商业签名/Apple 公证。电脑模式的手机操作功能需要更新至 v1.13.0 客户端；手机互联只需新版网页。双击新版客户端会在旧版保存完成后替换旧进程；记录保留。

从网页带入的是当前记录、术式设置、PVI 终点和电极选择；患者信息、PDF 和撤回历史不会转移。原网页的本机记录保留。显式切换操作端时接着最新共享记录操作，旧操作窗口继续只读跟随。

电脑记录位置：Windows `%LOCALAPPDATA%\VictoryPVI\record.json`；Mac `~/Library/Application Support/VictoryPVI/record.json`。删除或更换客户端不会删除这些记录。

实现、构建及发布说明见 [SYNC_DESIGN.md](./SYNC_DESIGN.md)。

报告中的患者信息均为选填，仅在当前页面内用于生成本次报告，不写入应用的本地存储。点击“导出 PDF 报告”后，应用会将患者基础信息、当前肺静脉消融分布和消融概览按照固定 A4 竖向版式在当前设备本地直接生成并下载；文字使用嵌入式中文字体，扇区图、表格、边框和进度条均以 PDF 原生矢量内容绘制，不调用浏览器打印功能，也不依赖网络服务。较长的“其它信息”会自动续排到后续页面，避免内容裁切。导出的 PDF 报告可能包含用户主动填写的信息，请按照所在机构的数据与隐私要求妥善处理。

普通单根肺静脉判定为消融完成需同时满足：前庭 8 个扇区均达到各自完成阈值，且该肺静脉口部与前庭的总消融次数不少于 4 次。其它扇区覆盖情况会继续单独显示；消融完成判定不替代 PVI 电生理终点评估。

## 重要说明

VictoryPVI 只提供记录和整理辅助，不替代：

- 发生器、三维标测系统或其他设备的原始数据；
- 肺静脉隔离终点评估；
- 医疗器械说明书、机构操作规范或质量体系；
- 医师的临床专业判断。
