# VictoryPVI

肺静脉消融记录辅助工具，由 VictoryPVI Community 维护。用于整理消融记录及在本机生成 PDF 报告。

当前网页版本：v1.15.0。

- [隐私说明](./PRIVACY.md)

本仓库仅用于发布静态网页。网页由独立维护的源代码仓库自动发布，请勿直接修改这里的文件。
